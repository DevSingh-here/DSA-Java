## About

- All solutions are written in **Java**.
- Problems are sourced primarily from **LeetCode** and **Striver's A2Z DSA Sheet**.
- Emphasis is on clean, optimized, interview-ready code over quick brute-force solutions.

## Coding Style

Every solution follows a consistent header format documenting the problem and its complexity:

```java
// LeetCode 1 - Two Sum
// Topic: Arrays, Hashing
// Difficulty: Easy
// Time: O(n)
// Space: O(n)

class Solution {
    public int[] twoSum(int[] nums, int target) {
        // implementation
    }
}
```

Each file includes:

| Field            | Description                          |
|------------------|---------------------------------------|
| Problem Name     | Title of the problem                  |
| Problem Number   | LeetCode/Sheet reference number       |
| Difficulty       | Easy / Medium / Hard                  |
| Time Complexity  | Big-O time analysis                   |
| Space Complexity | Big-O space analysis                  |
